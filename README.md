
# 🚀 Nikjoo Market (نیکجو)

Nikjoo is a high-performance, AI-powered classifieds marketplace built with **React**, **Tailwind CSS**, and **Google Gemini AI**.

![Nikjoo Preview](https://picsum.photos/seed/nikjoo-preview/800/400)

## ✨ Key Features

- 🧠 **AI-Powered Listing Optimization**: Uses Google Gemini to suggest better titles and descriptions for your ads.
- 💬 **Smart Support Chat**: Integrated AI assistant to help users in Persian.
- 📱 **Responsive Design**: Optimized for mobile and desktop using a "Mobile-First" approach.
- 📍 **Location-Based Search**: Advanced city and province filtering for the Iranian market.
- 🎨 **Modern UI/UX**: Clean, fast, and aesthetic interface inspired by top global marketplaces.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **AI Engine**: Google Generative AI (Gemini 3 Flash)
- **Icons & Assets**: Custom SVG & Unsplash/Picsum integration

## 🚀 How to Run Locally

1. **Clone the repo:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/nikjoo-marketplace.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file and add your Google AI Key:
   ```env
   API_KEY=your_gemini_api_key_here
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```
